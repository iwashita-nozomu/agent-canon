# Eval

This directory contains the implementation of AgentCanon evaluation only:
definitions, producers, checkers, and static fixtures. Those files are
reviewable source and remain in `eval/`; they do not own generated reports or
runtime logs.

- [definitions/README.md](definitions/README.md)
  - source-controlled manifests and the source/result boundary.
- `producers/`, `checkers/`, and `fixtures/`
  - eval implementation and static inputs.

All measurements, reports, packets, logs, dashboards, and other generated
results are external artifacts. Producers write only to an explicit bootstrap
runtime spool (for example `<install-root>/.runtime/spool/<run-id>/`), and
`eval sync` publishes the retained archive to the separate
[`iwashita-nozomu/agent-canon-log`](https://github.com/iwashita-nozomu/agent-canon-log)
repository at the external `<install-root-parent>/agent-canon-log/` checkout.
Nothing generated by an eval is written to this source directory.
The archive boundary and retry/readback contract are defined in
`documents/runtime/runtime-log-archive.md`.
