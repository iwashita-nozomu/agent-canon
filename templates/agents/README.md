Use a template when the selected writing or review task needs that artifact.
Choose the existing project owner and include the sections that express its
purpose, inputs, findings and evidence. Templates do not require task manifests,
progress files, schedules, approval receipts or a report for every role.

Codex provides agent collaboration. Git and the conversation carry task scope
and handoff. The former AgentTeam renderer and automatic run-bundle generation
are retired. Existing archived reports remain readable through their archive
owner.

The `_partials` directory contains shared reader and review structures. Reuse
that content when useful; no active run or template expansion is required.
Mathematical assumptions, proof obligations and experiment artifacts retain
their domain owners. A report describes actual results and their limitations.
